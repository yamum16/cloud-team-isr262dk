## Репозиторий

https://github.com/yamum16/cloud-team-isr262dk

## Назначение проекта

Справочник моделей облачного обслуживания IaaS / PaaS / SaaS с примерами
сервисов и учебное Flask-приложение, отдающее каталог по HTTP.

## Структура README.md

О проекте → Архитектура → Структура репозитория → Технологии → Запуск →
Автор → Ход работы.

## Использованные элементы Markdown

- заголовки (`#`, `##`);
- маркированные и нумерованные списки;
- таблицы (архитектура, структура репозитория, ход работы);
- ссылки на файлы репозитория и GitHub Docs;
- выделение (жирный текст);
- инлайн-код и блоки кода с подсветкой (команды запуска).

## Архитектурные компоненты

- **Клиент**: браузер или curl, отправляет HTTP-запросы.
- **Веб-приложение**: `app.py` на Flask, обрабатывает запросы `/` и `/services`.
- **Данные каталога**: список сервисов по категориям, используется приложением.
- **Конфигурация**: переменные окружения `APP_TITLE`, `PORT`, шаблон `config/example.env`.

## Вывод

Документация позволяет новому участнику понять назначение проекта,
его компоненты и порядок запуска, не изучая весь код. Для облачного
проекта это особенно важно: развёртывание выполняется на разных машинах
и в разных средах, и воспроизводимая инструкция в README экономит время
и уменьшает число ошибок. Хранение документации в том же репозитории,
что и код, позволяет обновлять её вместе с изменениями проекта.
