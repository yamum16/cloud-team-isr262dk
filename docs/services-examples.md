# Примеры облачных сервисов

## IaaS

| Сервис                        | Провайдер       | Что предоставляет                     |
|-------------------------------|-----------------|---------------------------------------|
| Amazon EC2                    | AWS             | виртуальные машины                    |
| Google Compute Engine         | Google Cloud    | виртуальные машины                    |
| Azure Virtual Machines        | Microsoft Azure | виртуальные машины                    |
| Yandex Compute Cloud          | Yandex Cloud    | виртуальные машины                    |

## PaaS

| Сервис                        | Провайдер       | Что предоставляет                     |
|-------------------------------|-----------------|---------------------------------------|
| Google App Engine             | Google Cloud    | платформа для запуска веб-приложений  |
| Azure App Service             | Microsoft Azure | хостинг веб-приложений и API          |
| AWS Elastic Beanstalk         | AWS             | автоматическое развёртывание приложений |
| Heroku                        | Salesforce      | платформа для запуска приложений      |

## SaaS

| Сервис                        | Провайдер       | Что предоставляет                     |
|-------------------------------|-----------------|---------------------------------------|
| Google Workspace              | Google          | почта, документы, таблицы             |
| Microsoft 365                 | Microsoft       | офисные приложения и почта            |
| Zoom                          | Zoom            | видеоконференции                      |
| GitHub                        | Microsoft       | хостинг Git-репозиториев              |
