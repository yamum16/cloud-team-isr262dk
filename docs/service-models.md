# Модели облачного обслуживания

## IaaS — Infrastructure as a Service

Провайдер предоставляет вычислительные ресурсы: виртуальные машины, сети,
диски. Пользователь сам устанавливает ОС, среду выполнения и приложения.

## PaaS — Platform as a Service

Провайдер предоставляет готовую платформу для запуска приложений
(ОС, среда выполнения, базы данных). Пользователь загружает только свой код
и данные.

## SaaS — Software as a Service

Провайдер предоставляет готовое приложение, доступное через браузер или
клиент. Пользователь только работает с программой и своими данными.

## Сравнение

| Уровень               | On-premise   | IaaS         | PaaS         | SaaS         |
|-----------------------|--------------|--------------|--------------|--------------|
| Приложения            | пользователь | пользователь | пользователь | провайдер    |
| Среда выполнения      | пользователь | пользователь | провайдер    | провайдер    |
| Операционная система  | пользователь | пользователь | провайдер    | провайдер    |
| Виртуализация         | пользователь | провайдер    | провайдер    | провайдер    |
| Серверы, сеть, диски  | пользователь | провайдер    | провайдер    | провайдер    |
