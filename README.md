# Cloud Team Project — Каталог облачных сервисов

Учебный проект по дисциплине «Основы облачных технологий».
Лабораторная работа № 3 «Организация командной работы в GitHub», вариант 1.

## Цель проекта

Собрать небольшой справочник облачных сервисов: модели обслуживания
IaaS / PaaS / SaaS и примеры реальных сервисов для каждой модели.
